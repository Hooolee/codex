## 🎯 核心问题

**在 100 以内，是否有两个连续自然数（n 和 n+1）满足它们的和等于它们之积与和的最大公因数？**

数学表达式：
```
n + (n+1) = gcd(n × (n+1), 2n+1)
```

等价于：
```
2n + 1 = gcd(n(n+1), 2n+1)
```

---

## ✅ 答案

**不存在这样的自然数 n。**

这个结论不仅适用于 100 以内，而是对**所有正整数**都成立。

---

## 📐 四种完整证明

### 1️⃣ 反证法（质数分解）

**定理**: ∀n ∈ ℕ⁺, gcd(n(n+1), 2n+1) = 1

**证明**: 假设 d = gcd(n(n+1), 2n+1) > 1，则存在质数 p | d。

- 若 p | n，则 p | (2n+1 - 2n) = 1，矛盾！
- 若 p | (n+1)，则 p | (2(n+1) - (2n+1)) = 1，矛盾！

因此 d = 1。 ∎

---

### 2️⃣ 辗转相除法

若 d | n(n+1) 且 d | (2n+1)，则：
- d | [2n(n+1) - n(2n+1)] = n
- d | [(n+1)(2n+1) - 2n(n+1)] = n+1
- 因此 d | gcd(n, n+1) = 1

所以 d = 1。 ∎

---

### 3️⃣ 代数方程（Pell 方程）

要使 (2n+1) | n(n+1)，需存在正整数 k 使得：
```
n² - (2k-1)n - k = 0
n = [(2k-1) ± √(4k²+1)] / 2
```

要使 n 是正整数，需 4k² + 1 = m²，即：
```
m² - 4k² = 1
(m-2k)(m+2k) = 1
```

唯一正整数解：m = 1, k = 0，此时 n = 0 或 n = -1，都不是正自然数。 ∎

---

### 4️⃣ 余数分析（构造性证明）

**余数公式**:
```
n(n+1) mod (2n+1) = ⎧ n/2        (n 为偶数)
                     ⎩ (3n+1)/2   (n 为奇数)
```

**证明**: 
- n = 2k 时：r = 4k² + 2k - k(4k+1) = k = n/2 ≥ 1
- n = 2k+1 时：r = 4k² + 6k + 2 - k(4k+3) = 3k+2 = (3n+1)/2 ≥ 2

对所有 n ≥ 1，余数 > 0，因此 (2n+1) ∤ n(n+1)。 ∎

## 🧮 深层数学意义

### 核心定理

**连续两个自然数的积与它们的和总是互质的。**

```
∀n ∈ ℕ⁺, gcd(n(n+1), 2n+1) = 1
```

### 为什么会这样？

1. **n 和 n+1 互质**: gcd(n, n+1) = 1
2. **2n+1 与 n 相差 1**: 2n+1 - 2n = 1
3. **2n+1 与 n+1 相差 1**: 2(n+1) - (2n+1) = 1

这种"相差 1"的关系确保了它们没有公共因子。

### 几何直观

在数轴上：
```
n -------- n+1 -------- 2n+1
   [间隔1]      [间隔n]
```

2n+1 恰好位于 n 和 n+1 的"中间偏右"位置，与两者都保持"相差 1"的关系。
